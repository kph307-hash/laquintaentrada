No tiene permisos de ubicación

Para usar su ubicación actual, debe permitir el acceso a la ubicación en su navegador.

iPhone con Chrome

  1. Cierre Chrome.
  2. Abra Ajustes en su iPhone.
  3. Busque y toque Chrome.
  4. Entre en Ubicación.
  5. Seleccione Mientras se usa la app.
  6. Vuelva a Chrome y regrese a esta página.

Android con Chrome

  1. Abra Chrome.
  2. Toque Configuración.
  3. Entre en Configuración de sitios.
  4. Abra Ubicación y verifique que esté permitida.
  5. Si no funciona, abra Ajustes del teléfono.
  6. Entre en Apps > Chrome > Permisos > Ubicación.
  7. Active el permiso de ubicación para Chrome.

Computadora con Chrome

  1. Abra Chrome.
  2. Entre a este sitio.
  3. Abra Configuración.
  4. Entre en Privacidad y seguridad.
  5. Abra Configuración de sitios.
  6. Entre en Ubicación.
  7. Permita el acceso a la ubicación para este sitio.

Después de activar el permiso, vuelva a esta página y toque Usar mi ubicación actual.
